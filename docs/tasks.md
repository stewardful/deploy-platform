## 已有验收

- 常规 Rust/Go/TS、真实跨语言 Socket、浏览器、安装器组件与静态检查。
- 隔离 Ubuntu ARM64 的实际 containerd/nerdctl、四服务、网络隔离、有状态恢复。
- 本地隔离 ACME CA 的签发/续期、真实 HTTPS、网页、代理重启恢复。

## 下一阶段：先完成自己的云节点验收

- [ ] 按 [腾讯云操作手册](tencent-ubuntu-walkthrough.md) 验证实际系统、安装、镜像访问、四服务和公网 HTTPS。
- [ ] 真实服务器重启后，running 应用恢复、stopped 应用保持停止、数据可读。

- [ ] 制定并验证数据库与证书存储备份恢复；数据保留不是备份。

## 后续功能

- [ ] 应用配置更新、镜像升级/回退及数据库迁移边界。
- [ ] 私有镜像仓库凭据、应用密钥轮换与静态加密方案。
- [ ] 任务/日志/旧发布版本保留与磁盘空间管理。

- [ ] 远程 Agent 认证、传输、账户和项目权限。

优先把一个真实项目的部署、数据备份和故障恢复跑稳，再扩展节点规模。Rust 负责高权限节点边界，Go 负责管理编排，Web 负责交互；新增功能沿现有组件复用，不复制另一套容器控制实现。
